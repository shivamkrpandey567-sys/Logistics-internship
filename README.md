## Project Overview
This project simulates an end-to-end logistics data analytics initiative for a major retail distribution network operating out of central hubs in Madhya Pradesh (Bhopal/Indore). The primary objective is minimizing last-mile delivery transit times and optimizing inventory distribution.

## Key Performance Indicators (KPIs)
1. **On-Time Delivery Rate (OTDR):** Target > 95%
2. **Inventory Turnover Ratio:** Target 6–8 times annually
3. **Cost per Delivery (CpD):** Target 12-15% reduction year-over-year

## Analytical Roadmap
* **Phase 1:** Data Collection & Integration
* **Phase 2:** Data Cleaning & Preprocessing
* **Phase 3:** Exploratory Data Analysis (EDA)
* **Phase 4:** Predictive Modeling (Random Forest) & Spatial Clustering (K-Means)
* **Phase 5:** Evaluation & Deployment

## Repository Structure
* `logistics_analysis.py`: Python scripts for data preprocessing, K-Means clustering, and Random Forest regression modeling.
* `requirements.txt`: Python package dependencies.
